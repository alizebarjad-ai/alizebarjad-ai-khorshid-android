# اپلیکیشن Native اندروید خورشید مفاخر

نسخه اول اپلیکیشن اختصاصی اعضای سازمان مردم‌نهاد خورشید مفاخر با Kotlin و Jetpack Compose.

## وضعیت فعلی
- اسکلت Native اندروید در حال توسعه است.
- اتصال شبکه بر پایه API رسمی پورتال طراحی شده است.
- هنوز Build، تست روی دستگاه واقعی، تست قرارداد API و بررسی امنیتی انتشار انجام نشده است.
- این مخزن به پورتال و دیتابیس تولیدی تغییری اعمال نمی‌کند.

## محیط توسعه
- Android Studio جدید
- JDK 17
- Android SDK با compileSdk 35
- Gradle 8.9 یا سازگار با Android Gradle Plugin 8.7.3

## سرویس
https://portal.khorshid-mafakher.ir

## محدوده نسخه اول
- ورود عضو با حساب فعلی پورتال
- بررسی نشست
- داشبورد عضو و اطلاعیه‌ها
- مکاتبات و پاسخ
- پیشنهاد پروژه
- پروفایل و خروج

## ملاحظات امنیتی
- هیچ دسترسی مستقیمی به دیتابیس از اپلیکیشن وجود ندارد.
- نشست در فضای رمزگذاری‌شده مبتنی بر Android Keystore نگهداری می‌شود.
- رمز عبور ذخیره نمی‌شود.
- لاگ‌کردن هدر Cookie ممنوع است.
- قبل از انتشار، اعتبارسنجی مالکیت داده‌ها و رفتار Same-Origin در API باید تست شود.

## ساخت
در Android Studio پروژه را باز کنید و Sync Gradle را انجام دهید. سپس:
```bash
gradle assembleDebug
```

برای خروجی فروشگاهی باید Release signing، شناسه نهایی بسته، سیاست حریم خصوصی، تست امنیت و AAB تکمیل شود.
