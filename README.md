# اپلیکیشن Native اندروید خورشید مفاخر

نسخه اول اپلیکیشن اختصاصی اعضای سازمان مردم‌نهاد خورشید مفاخر با Kotlin و Jetpack Compose.

## وضعیت توسعه
- نسخه سورس فعلی: **1.0.2** (versionCode 3)
- [x] اسکلت Native اندروید با Kotlin و Jetpack Compose
- [x] ورود با حساب فعلی پورتال و بررسی نشست
- [x] نگهداری کوکی نشست با رمزنگاری AES-GCM و کلید Android Keystore
- [x] دریافت داشبورد، اطلاعیه‌ها و اعلان‌های عضو
- [x] نمایش مکاتبات و ارسال پاسخ
- [x] ارسال مکاتبه جدید به واحدهای مجاز
- [x] دریافت پیشنهادهای پروژه عضو
- [x] ثبت پیشنهاد پروژه در گردش کار اصلی پورتال
- [x] نمایش پروفایل و باشگاه‌های عضو
- [x] درخواست عضویت در باشگاه‌های فعال از داخل اپ
- [x] نمایش فرصت‌ها و آگهی‌ها در داشبورد عضو
- [x] نمایش برنامه‌ها و رویدادها در داشبورد عضو
- [x] Gradle Wrapper استاندارد با Gradle 8.9
- [x] تعریف workflow دستی برای Build APK در GitHub Actions (اجرای خودکار غیرفعال برای حفظ سهمیه)
- [ ] Build واقعی در محیط محلی و تست روی شبیه‌ساز/دستگاه
- [ ] تست یکپارچگی با حساب آزمایشی و آزمون خطاهای شبکه
- [ ] بررسی نهایی امنیت و آماده‌سازی انتشار فروشگاهی

**توجه:** سورس قابلیت‌های اصلی نسخه اول را دارد، اما تا پیش از اجرای Build و تست واقعی، نسخه قابل نصب یا آماده انتشار محسوب نمی‌شود.

## ملاحظات امنیتی
- هیچ دسترسی مستقیمی به دیتابیس از اپلیکیشن وجود ندارد.
- کوکی نشست با AES-GCM و کلید غیرقابل‌استخراج Android Keystore رمزگذاری می‌شود.
- رمز عبور ذخیره نمی‌شود.
- درخواست‌های API با Origin برابر دامنه رسمی پورتال ارسال می‌شوند؛ حفاظت Origin سمت سرور تضعیف نشده است.
- لاگ‌کردن هدر Cookie ممنوع است.
- دسترسی‌ها و مالکیت مکاتبات و پروژه‌ها در سمت سرور کنترل می‌شوند.
- پیش از انتشار، رفتار نشست، انقضای نشست، خطاهای API و مجوزهای هر عملیات باید روی دستگاه واقعی آزموده شوند.

## ساخت محلی
در Android Studio پروژه را باز کنید و Gradle Sync را انجام دهید. سپس در PowerShell ریشه پروژه:
```powershell
.\scripts\build-debug.ps1
```
یا از ترمینال Gradle:
```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```
را اجرا کنید. چک‌لیست کامل ساخت و تست در `docs/BUILD-AND-RELEASE-CHECKLIST.md` است.

برای خروجی فروشگاهی باید Release signing، شناسه نهایی بسته، سیاست حریم خصوصی، تست امنیت و AAB تکمیل شود.
