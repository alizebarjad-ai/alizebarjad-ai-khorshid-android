# ساخت، آزمون و انتشار اپ اندروید خورشید مفاخر

## وضعیت فعلی

- نسخه سورس: 1.0.2 (versionCode 3)
- خروجی مورد انتظار: APK آزمایشی Debug
- ساخت روی Windows با Android Studio و JDK 17
- سرویس متصل: پورتال رسمی اعضا
- اپلیکیشن به دیتابیس متصل نمی‌شود؛ همه درخواست‌ها از API پورتال عبور می‌کنند.
- ساخت و تست روی دستگاه واقعی هنوز انجام نشده است.

## آماده‌سازی محیط

1. Android Studio را باز کنید و مخزن را از GitHub Clone کنید.
2. Gradle Sync را کامل کنید.
3. در صورت درخواست، Android SDK Platform 35 و Build Tools 35.0.0 را نصب کنید.
4. مطمئن شوید JDK 17 در دسترس است؛ Gradle 8.9 از طریق Wrapper دانلود می‌شود.

## ساخت APK

در PowerShell ریشه پروژه را باز کنید و اجرا کنید:

```powershell
.\scripts\build-debug.ps1
```

خروجی:

```
app\build\outputs\apk\debug\app-debug.apk
```

اسکریپت SHA-256 فایل خروجی را نیز نمایش می‌دهد. APK را فقط پس از بررسی مسیر و تاریخ ساخت، به‌عنوان خروجی همین سورس معرفی کنید.

## تست‌های خودکار

```powershell
 .\gradlew.bat testDebugUnitTest
 .\gradlew.bat assembleDebug
```

یا از پنجره Gradle در Android Studio، taskهای `testDebugUnitTest` و `assembleDebug` را اجرا کنید.

## آزمون پذیرش روی گوشی

این موارد تا دسترسی به گوشی واقعی باز هستند:

- نصب APK و بازشدن بدون crash
- ورود با حساب عضو واقعی و خروج
- پایان نشست و ورود مجدد
- نمایش اطلاعیه‌های داخلی و عمومی، بدون تکرار
- نمایش و پاسخ مکاتبات
- ثبت پیشنهاد پروژه و مشاهده پرونده در پورتال
- عضویت در یک باشگاه و مشاهده عضویت پس از refresh
- بازشدن لینک فرصت‌ها فقط با HTTPS
- رفتار مناسب در قطع اینترنت و خطای API
- بررسی خوانایی فارسی، راست‌چین بودن و اندازه متن در نمایشگر واقعی
