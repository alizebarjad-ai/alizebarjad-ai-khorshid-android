# ممیزی قرارداد API پورتال برای اپ اندروید

تاریخ بررسی: ۱۴۰۵/۰۹/۰۳

این سند بر اساس سورس شاخه `main` مخزن `alizebarjad-ai/khorshid-portal-v2` تهیه شده است. هیچ تغییری در مخزن پورتال یا دیتابیس اعمال نشده است.

## قرارداد احراز هویت تأییدشده

### ورود
- روش: `POST /api/auth/login`
- بدنه JSON دقیق و strict:
  - `username`: رشته، پس از trim، حداکثر ۱۰۰ نویسه
  - `password`: رشته، حداکثر ۱۰۲۴ نویسه
- پاسخ موفق: `{ "ok": true }`
- پاسخ ناموفق ممکن است 400، 401، 403، 429 یا 503 باشد.
- هدر `Origin` اجباری است و باید با host و پروتکل درخواست مطابقت داشته باشد. در محیط تولید، پروتکل مورد انتظار HTTPS است.
- ورود هم با نام کاربری و هم با ایمیل حساب امکان‌پذیر است.

### نشست
- نام کوکی: `khorshid_session`
- ویژگی‌های کوکی در پورتال: `HttpOnly`، `Secure` در تولید، `SameSite=Lax`، مسیر `/`
- عمر نشست: ۸ ساعت
- توکن نشست تصادفی است؛ فقط hash آن در دیتابیس ذخیره می‌شود.
- `GET /api/auth/session` در حالت معتبر پاسخ `{ ok: true, authenticated: true, user: { username } }` می‌دهد؛ در حالت نامعتبر HTTP 401 و `authenticated: false`.
- نشست با تغییر credential version، غیرفعال شدن حساب، انقضا یا revoke نامعتبر می‌شود.

### خروج
- روش: `POST /api/auth/logout`
- این مسیر نیز `Origin` معتبر می‌خواهد.
- خروج نشست سمت سرور را revoke و کوکی را پاک می‌کند.

## مواردی که هنوز تأیید نشده‌اند

1. مسیر `/api/workspace/member` که در نسخه اولیه اپ استفاده شده، در مسیرهای بررسی‌شده پورتال پیدا نشد؛ بنابراین نباید آن را API معتبر فرض کرد.
2. پاسخ `/api/auth/session` فقط username را برمی‌گرداند و برای تشخیص قطعی نقش MEMBER یا دریافت نام نمایشی عضو کافی نیست.
3. APIهای واقعی اطلاعیه‌ها، مکاتبات، پاسخ پیام، پیشنهاد پروژه و پروفایل هنوز از سورس پورتال استخراج و تأیید نشده‌اند.
4. باید کنترل دسترسی سمت سرور برای اطمینان از اینکه حساب‌های غیرعضو وارد اپ اعضا نمی‌شوند، در endpointهای واقعی بررسی شود.

## تصمیم پیاده‌سازی

- سیاست امنیتی Origin پورتال تضعیف یا حذف نشود.
- از APIهای ساختگی یا حدس‌زده‌شده استفاده نشود.
- قبل از توسعه داشبورد، باید مسیر و قرارداد endpointهای واقعی عضو و کنترل نقش MEMBER از سورس پورتال استخراج شود.
- هیچ تغییری در پورتال تولیدی، دیتابیس یا داده‌های کاربران در این مرحله انجام نشده است.
- Build اندروید هنوز اجرا نشده و این ممیزی، تأیید Build محسوب نمی‌شود.
